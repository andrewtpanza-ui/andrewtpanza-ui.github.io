Starting with Vim

When you start with Vim you need to understand how to enter, and navigate Vim.
First, navigate to terminal, and use the following : vim name.html

Helpful Navigation Commands

The navigation may seem complex, but here are the basic commands to move around and operate Vim.

  • Esc Return to normal mode
  • A Insert at line end
  • vim file.html> Open file in vim from terminal
  • :wq Save and quit (only works while in Normal Mode)
  • H,J,K,L Left, Down, Up, and Right.
  • i Enter insert mode (edit)

Starter Minimal HTML page

We have used VIM primarily to code HTML for assignments. To code html you need to have a rough baseline to work with before you make your website entirely yours.

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Hello World!</title>
    
</head>
<body>
    <header>
        <h1>Hello World!</h1>
    </header>
    <main>
        <section>
            <h2>About Me</h2>
            <p>This is my first web page.</p>
        </section>
    </main>
    <footer>
        <p>Made by me.</p>
    </footer>
</body>
</html>
Output:
Hello World! About Me This is my first web page. Made by me.

Made by me.
